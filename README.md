# BODY QUEST – ההרפתקה הגדולה בתוך הגוף

משחק הרפתקאות תלת־ממדי וחינוכי לילדים בגילאי 9–12. השחקן חוקר עולם דמיוני בתוך גוף האדם ולומד על תזונה נכונה דרך משחק.

## הפעלה במחשב

1. לחצו פעמיים על הקובץ **`start.bat`**.
2. הדפדפן ייפתח לבד בכתובת `http://localhost:8080`.
3. כדי לעצור את המשחק, סגרו את החלון השחור.

אי אפשר לפתוח את `index.html` ישירות בלחיצה כפולה. הדפדפן חוסם משחק שמורכב מכמה קבצים כשהוא נפתח מהדיסק, ולכן צריך את `start.bat`.

אפשרות נוספת היא להריץ את הפקודה הבאה בטרמינל, מתוך תיקיית המשחק:

```
node tools/serve.mjs --open
```

## הפעלה בטלפון באותה רשת Wi-Fi

1. הפעילו את `start.bat` במחשב.
2. בחלון השחור מופיעה שורה כמו `On your phone (same Wi-Fi): http://192.168.1.23:8080`.
3. הקלידו את הכתובת הזו בדפדפן בטלפון.

בפעם הראשונה Windows עשוי לשאול אם לאפשר ל-Node.js גישה לרשת. אשרו גישה לרשתות פרטיות.

## הפעלה מכל מקום (Vercel)

אחרי שמעלים את הפרויקט ל-GitHub ומחברים אותו ל-Vercel, מקבלים כתובת קבועה שעובדת בכל מכשיר. אחרי הטעינה הראשונה המשחק נשמר במכשיר ונטען מהר.

## סיפור ואתגרי חשיבה (שלב D)

הסיפור: מוחי שכח איפה שם את תוכנית האיזון, ולכן כל BIOVERSE הפסיק לעבוד. המשחק נפתח במסך סיפור ונגמר בלוח הבקרה במרכז העולם, עם מסך סיום. אחרי הסיום אפשר להמשיך לשחק, וכל החברים מחכים במרכז העולם.

| מקום | אתגר חשיבה |
|---|---|
| עיר האנרגיה | דלק למסע הרכבת |
| מפעל הבנייה | השלד של שרירון |
| ג'ונגל הצבעים | צמרת העץ, ושבוע של צבעים במערה הסודית |
| ממלכת המים | אריזה למסע ביום חם |
| עיר החיים | מכינים ארוחה, אורזים תיק, ותכנון יום לימודים עד 16:00 |
| מרכז העולם | להרכיב את תוכנית האיזון |

כל אתגר הוא לוח אחד ב-`src/data/boards.js`, והמשחק נותן רמזים עד שהתוכנית עובדת. אין עונש על בחירה ויש כמה תשובות נכונות. החברים אומרים דברים חדשים אחרי כל משימה גדולה.

## ליטוש (שלב E)

- תפריט ראשי: ממשיכים לשחק, משחק חדש, הגדרות והישגים.
- 14 הישגים שנשמרים, והודעה כשמרוויחים אחד.
- סדנת השדרוגים במרכז העולם: נעלי מהירות, קפיץ בנעל ומגנט מטבעות, נקנים במטבעות ונשמרים.
- תנועה בהפעלת מכונה, ניצוצות באיסוף, אבק בנחיתה וחגיגה בסיום משימה. כל האפקטים מגיעים ממאגר קבוע, בלי יצירת עצמים בזמן המשחק.
- המשחק נעצר לבד כשעוזבים את האפליקציה.

## בדיקות

| כתובת | מה היא עושה |
|---|---|
| `?debug=1` | מציגה FPS, מספר draw calls, משולשים ורמת גרפיקה |
| `node tools/serve.mjs --slow` | מדמה חיבור איטי (כ-160KB לשנייה) כדי לבדוק את מסך הטעינה |

## שליטה

| פעולה | מחשב | טלפון |
|---|---|---|
| הליכה קדימה / לאחור | W S או ↑ ↓ | ג'ויסטיק מימין: קדימה / אחורה |
| סיבוב | A D או ← → | ג'ויסטיק מימין: הצידה |
| ריצה | Shift | דחיפת הג'ויסטיק עד הסוף |
| קפיצה | רווח (להחזיק לקפיצה גבוהה) | כפתור "קפיצה" (משמאל) |
| פעולה | E | כפתור "פעולה" |
| תיק · משימות · מפה | I · J · M | הכפתורים למעלה |
| מצלמה | גרירת עכבר, וגלגלת לזום | החלקת אצבע |
| השהיה | Esc | כפתור ⏸ |

ברירת המחדל היא שליטה "כמו רכב": המצלמה תמיד מאחורי הדמות, והנסיעה לאחור לא מסובבת אותה. בתפריט ההשהיה אפשר לעבור ל"שליטה: חופשית", שבה הדמות הולכת לכיוון שלוחצים, ביחס למצלמה.

## מבנה הפרויקט

```
index.html            מסך הטעינה + importmap
src/boot.js           טוען את כל הקבצים מראש עם אחוזי התקדמות אמיתיים
src/main.js           נקודת הכניסה
src/Game.js           מחבר את כל המערכות
src/core/             מנוע, קלט, איכות גרפיקה, מצב debug
src/player/           תנועת השחקן ומצלמה בגוף שלישי
src/characters/       בניית דמויות השחקן והחברים (NPCs.js) ואנימציה פרוצדורלית
src/world/            ניהול אזורים, התנגשויות, אבני בניין (Props, Structures, Fruit), חומרים
src/world/Bake.js     איחוד עצמים סטטיים לכמה רשתות בודדות, כדי שהעולם ירוץ מהר בטלפון
src/world/zones/      מרכז העולם, חמשת האזורים וזירת האימונים
src/systems/          אינטראקציות, חברים, משימות, תיק, פריטים לאיסוף, אתגרי זמן, צלילים, שמירה
src/missions/         המשימות של כל אזור (מכונות, שערים, מנוף, שסתומים...)
src/minigames/        הזנת מכונה, פס המיון, חידת הצינורות, המכולת, לוח התכנון
src/ui/               ממשק, HUD, מפה קטנה, מסכי תיק/משימות/מפה, סיפור וסיום, שליטת מגע, בחירת דמות
src/data/             נתוני תוכן: דמויות, אזורים, פריטים, משימות, אתגרי חשיבה, מה החברים אומרים
vendor/three/         Three.js r170 (רישיון MIT)
assets/fonts/         גופן Rubik (רישיון OFL)
sw.js                 Service Worker: שמירת המשחק במכשיר
tools/                שרת מקומי ויצירת asset-manifest.json
```

אחרי שמוסיפים או משנים קבצים צריך להריץ את `node tools/build-manifest.mjs`. ‏`start.bat` כבר מריץ אותה אוטומטית.
