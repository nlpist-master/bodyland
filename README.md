# BODY QUEST – ההרפתקה הגדולה בתוך הגוף

משחק הרפתקאות תלת־ממדי וחינוכי לילדים בגילאי 9–12. השחקן חוקר עולם דמיוני בתוך גוף האדם ולומד על תזונה נכונה דרך משחק.

## הפעלה במחשב

1. לחצו פעמיים על הקובץ **`start.bat`**.
2. הדפדפן ייפתח לבד בכתובת `http://localhost:8080`.
3. כדי לעצור את המשחק, סגרו את החלון השחור.

אי אפשר לפתוח את `index.html` ישירות בלחיצה כפולה. הדפדפן חוסם משחק שמורכב מכמה קבצים כשהוא נפתח מהדיסק, ולכן צריך את `start.bat`.

אפשרות נוספת היא להריץ את הפקודה הבאה בטרמינל, מתוך תיקיית המשחק:

```
node tools/serve.mjs --open
```

## הפעלה בטלפון באותה רשת Wi-Fi

1. הפעילו את `start.bat` במחשב.
2. בחלון השחור מופיעה שורה כמו `On your phone (same Wi-Fi): http://192.168.1.23:8080`.
3. הקלידו את הכתובת הזו בדפדפן בטלפון.

בפעם הראשונה Windows עשוי לשאול אם לאפשר ל-Node.js גישה לרשת. אשרו גישה לרשתות פרטיות.

## הפעלה מכל מקום (Vercel)

אחרי שמעלים את הפרויקט ל-GitHub ומחברים אותו ל-Vercel, מקבלים כתובת קבועה שעובדת בכל מכשיר. אחרי הטעינה הראשונה המשחק נשמר במכשיר ונטען מהר.

## בדיקות

| כתובת | מה היא עושה |
|---|---|
| `?debug=1` | מציגה FPS, מספר draw calls, משולשים ורמת גרפיקה |
| `node tools/serve.mjs --slow` | מדמה חיבור איטי (כ-160KB לשנייה) כדי לבדוק את מסך הטעינה |

## שליטה

| פעולה | מחשב | טלפון |
|---|---|---|
| הליכה | W A S D או חיצים | ג'ויסטיק משמאל |
| ריצה | Shift | כפתור "ריצה" (הפעלה וכיבוי) |
| קפיצה | רווח (להחזיק לקפיצה גבוהה) | כפתור "קפיצה" |
| פעולה | E | כפתור "פעולה" |
| מצלמה | גרירת עכבר, וגלגלת לזום | החלקת אצבע |
| השהיה | Esc | כפתור ⏸ |

## מבנה הפרויקט

```
index.html            מסך הטעינה + importmap
src/boot.js           טוען את כל הקבצים מראש עם אחוזי התקדמות אמיתיים
src/main.js           נקודת הכניסה
src/Game.js           מחבר את כל המערכות
src/core/             מנוע, קלט, איכות גרפיקה, מצב debug
src/player/           תנועת השחקן ומצלמה בגוף שלישי
src/characters/       בניית דמויות ואנימציה פרוצדורלית
src/world/            ניהול אזורים, התנגשויות, אבני בניין, חומרים
src/world/zones/      האזורים עצמם
src/systems/          אינטראקציות, צלילים, שמירת התקדמות
src/ui/               ממשק, שליטת מגע, בחירת דמות
src/data/             נתוני תוכן (דמויות וכו')
vendor/three/         Three.js r170 (רישיון MIT)
assets/fonts/         גופן Rubik (רישיון OFL)
sw.js                 Service Worker: שמירת המשחק במכשיר
tools/                שרת מקומי ויצירת asset-manifest.json
```

אחרי שמוסיפים או משנים קבצים צריך להריץ את `node tools/build-manifest.mjs`. ‏`start.bat` כבר מריץ אותה אוטומטית.
